# Kestrel Support and API

## Support hours
Support is available Monday to Friday, 9 am to 5 pm Atlantic time. Plus users get a reply within 1 business day. Team users get a reply within 4 hours during support hours. Free users can use the community forum.

## Export
Notes can be exported as Markdown, PDF, or HTML.

## API
The Kestrel API allows up to 120 requests per minute per account. Requests over the limit receive an HTTP 429 response. Webhooks are available on the Team plan only.

## Troubleshooting sync
If a note is not syncing, check the Relay status page first. Attachments larger than 25 MB will fail to sync and show a yellow warning icon.
