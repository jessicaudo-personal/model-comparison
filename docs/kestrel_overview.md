# Kestrel Overview
Kestrel is an offline-first note-taking app made by Tidewater Labs, a small software company founded in 2021 in Halifax, Nova Scotia. Tidewater Labs was co-founded by Priya Raman and Tomas Eklund.

## Release history
Kestrel version 1.0 launched on 14 March 2022 for macOS and iOS. Windows support arrived in version 2.0 (October 2022), and Android support in version 2.4 (June 2023). A Linux beta has been available since February 2026.

## How syncing works
Kestrel stores every note on the device first, so the app works without an internet connection. When a connection is available, a background service called Relay syncs notes between a user's devices. Relay retries failed syncs automatically every 5 minutes.

## Limits
A single note can be up to 25 MB, including attachments. The Free plan allows up to 500 notes.
